HELIODROME — a 5v5 round-based tactical FPS in a desert solar array at golden dusk. Plant the spike at Panel Field (A) or Inverter Yard (B), or eliminate the defenders. First to 7 rounds takes the match, max 12. Team-plan bots with radio callouts, a buy economy with five weapons and three grenades, aim-down-sights, a defuse kit, and a full HUD with minimap, kill feed and location labels.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
